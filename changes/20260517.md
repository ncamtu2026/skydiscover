## Summary of changes

### Core implementation
- Added `KnowledgeBaseConfig` to config.py
  - `enabled`, `source_path`, `max_matches`, `retrieval_method`, `include_solution_snippets`, `embedding_model`
- Added new module knowledge_base.py
  - `KnowledgeBase` loads JSON/JSONL KB entries
  - `KnowledgeBaseEntry` contains `task`, `task_formalization_and_decomposition`, `solution`, `source`, and metadata
  - Simple text-overlap retrieval implemented

### Controller integration
- Updated default_discovery_controller.py
  - imports `KnowledgeBase`
  - initializes KB in `DiscoveryController.__init__`
  - builds a retrieval query from system message / evaluator context
  - injects `knowledge_examples` and `knowledge_query` into prompt context

### Prompt builder updates
- Updated builder.py
  - added `_format_knowledge_examples(...)`
  - passes `knowledge_examples` / `knowledge_query` into template rendering

### Template updates
- Added `{knowledge_examples}` placeholder to default templates:
  - full_rewrite_user_message.txt
  - diff_user_message.txt
  - from_scratch_user_message.txt
  - image_user_message.txt
  - full_rewrite_prompt_opt_user_message.txt

### Unit tests added
- test_knowledge_base_config.py
  - verifies `KnowledgeBaseConfig` defaults
  - verifies config round-trip serialization / deserialization
- test_knowledge_base.py
  - verifies loading JSONL and JSON KB sources
  - verifies retrieval behavior
- test_default_builder_kb.py
  - verifies default builder renders knowledge examples in prompt output

### Validation
- Syntax check passed for modified files:
  - config.py
  - knowledge_base.py
  - default_discovery_controller.py
  - builder.py
